Overview

Alibaba Cloud (Alibaba Group) ให้บริการ Cloud Computing ครอบคลุมการประมวลผล จัดเก็บข้อมูล เครือข่าย ฐานข้อมูล ความปลอดภัย Big Data และ AI เว็บนี้เป็นสื่อการเรียนรู้เชิงวิชาการ ไม่ใช่เว็บทางการของ Alibaba Cloud

Global Infrastructure

Alibaba Cloud จัดโครงสร้างเป็น Region (พื้นที่ทางภูมิศาสตร์) ซึ่งประกอบด้วย Availability Zone (กลุ่ม Data Center ที่แยกกันทางโครงสร้างพื้นฐาน) เชื่อมต่อกันด้วย Global Network

เลือกจุดบนแผนที่

แผนที่นี้เป็นภาพแสดงแนวคิด ตำแหน่งโดยประมาณ ไม่ครบทุก Region จำนวนและรายชื่อ Region ล่าสุดโปรดตรวจสอบที่หน้า Global Infrastructure ทางการ (ดู References)

Strengths & Considerations

STRENGTHS

  • โครงสร้างพื้นฐานหลาย Region ทั่วโลก
  • ขยายระบบได้ตามความต้องการ (Scalability)
  • พอร์ตโฟลิโอบริการกว้าง ตั้งแต่ IaaS ถึง AI
  • ฟีเจอร์สำหรับองค์กรและความปลอดภัย

CONSIDERATIONS

  • โครงสร้างราคาซับซ้อน ต้องวางแผนต้นทุน
  • ต้องใช้เวลาเรียนรู้เครื่องมือและบริการ
  • ความเสี่ยง Vendor Lock-in หากใช้บริการเฉพาะเจ้า
  • ความพร้อมของบริการต่างกันในแต่ละ Region

Conclusion

Alibaba Cloud เป็นตัวเลือก Cloud ที่ครอบคลุมตั้งแต่โครงสร้างพื้นฐานจนถึง AI การเลือกใช้ควรพิจารณาความต้องการงาน ต้นทุน และ Region ที่เกี่ยวข้อง ควบคู่กับการศึกษาเอกสารทางการ
